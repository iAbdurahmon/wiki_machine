# Articles the project loads. One Wikipedia title per line. Any article on English
# Wikipedia works -- nothing has to be prepared for it. Underscores or spaces both
# work, the first letter is case-insensitive, and redirects are followed (writing
# NYC loads New York City). Lines starting with # are ignored.
#
# TO ADD AN ARTICLE: write its title below, then run
#
#     .venv/bin/python -m backend.loader          (Windows: .venv\Scripts\python -m backend.loader)
#
# Articles already in the database are skipped, so that run only fetches the new ones.
# Use --reset to throw the revisions away and load the whole list again from scratch.
#
# This list is the shared one: everybody runs the loader with no arguments and ends up
# with the same database. Add a title here rather than loading it only on your machine.
#
# Cost is requests, not disk: the API returns 500 revisions per call, so a 30,000
# revision article means ~60 calls. The rows themselves are about 40 bytes each.

Agapanthus
Michael Jackson
Albert Einstein
Tashkent
New York City
